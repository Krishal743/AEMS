Each row adds one change; weights retuned on validation per row.

| A0 | text only | 0.3891 [0.3747, 0.4016] | — | — |

| A2 | + per-query z-scoring | 0.4008 [0.3871, 0.4142] | −0.0063 sig | +0.0002 n.s. |

| A4 | + passage branch | 0.4597 [0.4467, 0.4734] | +0.0526 sig | +0.0473 sig |
| A5 | + adaptive gating (cross-fitted) | 0.4616 [0.4487, 0.4760] | +0.0020 n.s. | +0.0141 sig |
| A5' | + gating **without** cross-fitting | 0.4177 [0.4042, 0.4324] | −0.0420 sig | −0.0269 sig |

Cross-fitting the gate's training audio is worth +0.0439 R@1 [+0.0361, +0.0520].

Two results contradict claims made earlier in development:
- **z-scoring is not worth a point on its own.** Against fixed weights tuned per
  configuration it costs 0.6 points. Its value is making branches comparable so
  the gate can work, not raw recall.
- **Adaptive gating does not beat tuned fixed weights on R@1** (+0.0020, CI spans
  zero). It wins on R@5 (+0.0141), MRR, and on validation.

The passage branch is the single largest contributor (+0.0526).

## Stage 2 — reranking

Stage-1 recall@K (the ceiling for any reranker): 0.708 @20, 0.771 @50,
0.817 @100 on test.

| Reranker | test R@1 [95% CI] | Δ vs stage 1 | text-answerable | visual | ms/query |
|---|---|---|---|---|---|
| Per-candidate gating | 0.4711 [0.4575, 0.4848] | +0.0094 [+0.0035, +0.0147] | 0.6171 | 0.3846 | 0.1 |
| **MiniLM cross-encoder** | **0.5866** [0.5725, 0.6002] | **+0.1250** [+0.1142, +0.1352] | 0.7716 | 0.4770 | 12.0 |
| BGE-reranker-v2-m3 | 0.5925 [0.5790, 0.6064] | +0.1309 [+0.1189, +0.1413] | 0.7780 | 0.4827 | 87.0 |

Tuned on validation: K=50 candidates, 3 passages each, blend weight 0.25
(MiniLM) / 0.5 (BGE).

**Deployed: MiniLM.** On the validation split used for selection it beat BGE
(0.6184 vs 0.6135). On test BGE is 0.6 points higher, which sits inside the
overlap of the two intervals, at 7x the latency and 25x the model size. The
per-candidate gate is significant but small: it reweights scores stage 1 already
produced, so it cannot introduce evidence the branches missed.

Split by question type: questions answerable from the transcript gain +0.165
(0.607 → 0.772); visual questions still gain +0.102, since transcripts describe
more visual content than a word-overlap heuristic detects.

## Visual branch diagnosis (validation)

| | R@1 |
|---|---|
| Current system | 0.5016 |
| Visual branch removed | 0.4846 |
| Visual branch perfect (oracle) | 0.9988 |
| Temporal-transformer visual embeddings instead of mean-pooled | 0.4767 (branch alone 0.1289) |

CLIP ViT-B/32 contributes only +1.7 points, while a perfect visual branch would
nearly solve the task — the branch is weak, not unimportant. The temporal
transformer variant is worse than frame averaging and should not be used.
