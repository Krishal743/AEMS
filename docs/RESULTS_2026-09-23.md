## Change from the previous pipeline

| Metric | Before | Now |
|---|---|---|
| Best system R@1 | 0.3894 (gate collapsed to text) | 0.4153 |
| R@10 | 0.5539 | 0.6229 |
| Audio-only R@1 | 0.0043 (CLAP zero-shot) | 0.0532 (WavLM + adapter) |

Three changes produced this: per-query z-scoring of each branch before
fusion; WavLM-Large plus a CLIP-space adapter replacing CLAP; and training
the gate on cross-fitted (out-of-fold) audio, without which it over-trusts
audio and scores 0.34 — below fixed weights.

## Caveats

- Single evaluation run; no bootstrap confidence intervals in this table. The
  gate-vs-fixed gain measured separately was +0.007 R@1, CI excluding zero
  across seeds 42/100/200.
- Audio remains the weakest branch. AEMS is speech-heavy educational video, so
  the spoken content is already captured by the transcript in the text branch.
- Fixed fusion weights come from a validation grid search. On test, the earlier
  values (0.25 / 1.0 / 0.15) happened to score 0.4106 versus 0.4071 for the
  validation-tuned (0.3 / 1.0 / 0.2); the tuned values are kept, since choosing
  by test score would be selection on the test set.
