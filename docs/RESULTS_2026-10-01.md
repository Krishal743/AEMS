## Deployed configuration

**Stage 1** — five branches, each z-scored per query over the gallery, combined
with per-query weights from the gating network:

| Branch | Encoder | Gate weight (mean ± std) |
|---|---|---|
| Visual | CLIP ViT-B/32, 16 frames mean-pooled | 0.169 ± 0.106 |
| Text (caption) | CLIP text, description + transcript, chunk-averaged | 0.310 ± 0.123 |
| Passage | CLIP text per chunk, scored by best passage | 0.129 ± 0.070 |
| Audio | WavLM-Large → trained adapter → CLIP text space | 0.149 ± 0.071 |
| BM25 | lexical over passages + title/description/tags | 0.243 ± 0.095 |

Four branches share one embedding space (the adapter projects audio into CLIP
text space), so a text query is encoded once and scores all four. BM25 is not in
any vector space; it is made comparable by z-scoring, not by shared geometry.

**Stage 2** — the top 100 candidates are rescored by a MiniLM cross-encoder
fine-tuned on AEMS, reading the query against each candidate's 8 best passages
(max-pooled). Final score = stage-1 score + 0.3 × z-scored reranker score, with
candidates lifted above videos the reranker never saw. K, passages and blend
weight were tuned on validation; 5 passages beat 3 and 8 beat 5, while K=200 did
not beat K=100 — reading more of each candidate matters more than shortlisting
more of them.

## By category (deployed system)

| Strongest | R@1 | Weakest | R@1 |
|---|---|---|---|
| Tech Reviews | 0.826 | Pronunciation Guides | 0.473 |
| Engineering Projects | 0.811 | Motivational Talks | 0.555 |
| Cooking Tutorials | 0.802 | Marketing Strategies | 0.609 |

The pattern is interpretable: categories with concrete, nameable subject matter
do well, while Pronunciation Guides — videos about *how words sound* rather than
what is said — are hardest, which is where text matching should struggle most.
Adaptive gating beats tuned fixed weights in 15 of 17 categories (range −0.016 to
+0.079).

## Caveats

**1. The lexical gain is partly an artifact of the benchmark.** A query's content
words appear in its own transcript 4.6× more often than in a random transcript
(44% vs 9.5%). The QA questions evidently reuse transcript wording, so BM25's
+0.16 over text-only would likely shrink on free-form user queries. This affects
the single largest stage-1 contributor and should be stated whenever the number
is quoted.

**2. Test was observed repeatedly, not held out blind.** Every selection decision
was made on validation, but the evaluation harness prints test metrics on each
run, so test numbers were seen many times during development. This is weaker than
a single sealed evaluation and the honest description is "test used for reporting,
validation used for every choice".

**3. Only text queries are evaluated.** All 5,097 test queries are QA questions.
Image, video and audio query paths exist but are unmeasured; the cross-encoder
cannot serve them at all, since it scores text against text.

**4. Audio contributes little.** 0.053 R@1 alone, and the WavLM swap was worth
+0.006 R@1 (not significant) over CLAP in the four-branch ablation. It earns its
0.149 gate weight through fusion, not standalone strength.
